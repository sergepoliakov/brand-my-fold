# Contributing

Contributions are welcome through focused issues and pull requests.

1. Keep public builds free of wallet addresses and secrets.
2. Preserve the one-to-one spot mapping across open and folded views.
3. Add or update tests for payment, authorization or auction-state changes.
4. Run `npm test` before opening a pull request.
5. Do not add third-party trademarks or device renders without clear rights.

By contributing, you agree that your contribution is provided under the project's MIT License.
